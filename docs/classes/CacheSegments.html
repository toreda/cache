    Class CacheSegments<ItemT>

    Internal probation/protected segmentation accounting (SLRU, 2Q, ARC). Instantiated by Cache only when cfg.segments.enabled. Tracks per-segment counts and item membership via PolicyMeta.segment; runs off internal paths and never depends on user events.
